# Sulzer Changeover Module Test Matrix

## Overview
The Sulzer Changeover module manages operational process duration baselines across Knotting, FC Knotting, and Threading procedures.

## Core Workflows
1. Navigation from Master Data menu.
2. Selecting category tab (Knotting, FC Knotting, Threading).
3. Inputting DD:HH:MM:SS duration string.
4. Saving/Refreshing changes.
