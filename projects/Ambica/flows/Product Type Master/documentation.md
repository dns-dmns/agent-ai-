# Product Type Master Test Suite Documentation

## Overview
This document provides comprehensive testing specifications for the **Product Type Master** component within the Ambica Enterprise ERP suite.

## Workflow Steps Covered
1. **Navigation**: Master Data -> Product Type Master
2. **Creation**: Opening modal, entering Name and Description, Submitting.
3. **Read**: Viewing details dialog modal.
4. **Update**: Modifying description and toggling active status.
5. **Delete**: Confirming deletion and handling cancellation.
6. **Validation**: Isolated single-field boundary and error checks.
