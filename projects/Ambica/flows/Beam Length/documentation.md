# Beam Length Master Data Module QA Documentation

## Workflow Summary
1. **Navigation**: User accesses the **Master Data** dropdown and selects **Beam Length**.
2. **Creation**: Clicking **Add Record** opens a modal to specify `#denier`, `#reed`, `#beamSize`, `#beamMeter`, and `#beamDish` values.
3. **View & Edit**: Table rows feature action buttons to view detailed parameters in modal windows or edit existing technical configurations.
4. **Deletion**: Deleting a record prompts a confirm dialog with **Yes, Delete** or **Cancel** options.
5. **Search & Filter**: Users filter entries using the **Search by Denier, Reed** input and restore default lists using **Reset**.
