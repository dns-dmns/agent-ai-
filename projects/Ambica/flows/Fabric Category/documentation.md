# Fabric Category Master Workflow

## Overview
The Fabric Category workflow allows quality engineers and enterprise system managers to control master fabric records, assign records to specialized Sulzer weaving machinery, and generate filtered exports.

## Workflow Steps
1. Navigate to **Master Data** -> **Fabric Category**.
2. Click **Add Fabric Category**.
3. Enter Category Name in `#fabricCategory` input field.
4. Save and manage machine assignments via **Assign to Sulzer Machines**.
5. Filter records using **Search by Fabric Category** or clear filters using **Reset**.
6. Export records to spreadsheet using the **Excel** export button.
