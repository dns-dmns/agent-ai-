# Production Capacity Master Data Workflow

## Overview
The Production Capacity workflow allows administrators to filter, view, create, update, and manage capacity bounds for specific width and category master records.

## Step-by-Step Flow
1. **Navigate**: Click on **Master Data** in the navigation menu and select **Production Capacity**.
2. **Filter**: Enter search criteria in the `Search by width/category` field to filter records.
3. **Edit**: Locate the target record and input the updated capacity numerical value in the field with placeholder `-`.
4. **Save**: Click **Save** to commit updates to the database.
5. **Refresh**: Click **Refresh** to re-sync grid records with backend state.
