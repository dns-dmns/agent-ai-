======================================================================
              QA AUTOMATION SUITE - GETTING STARTED GUIDE
======================================================================

Follow these simple steps to start, configure, and operate the platform.

----------------------------------------------------------------------
STEP 1: START THE APPLICATION SERVER
----------------------------------------------------------------------
Choose ONE of the options below to run the server:

Option A (Easiest):
  Double-click the file named "start_server.bat" in the D:\Ai folder.

Option B (Command Prompt / CMD):
  1. Open a Command Prompt (CMD) window.
  2. Navigate to your project folder:
     cd /d D:\Ai
  3. Activate the virtual environment:
     .venv\Scripts\activate.bat
  4. Run the application:
     python -m uvicorn qa_agent:app --host 127.0.0.1 --port 8000

Option C (PowerShell):
  1. Open a PowerShell window.
  2. Navigate to your project folder:
     cd D:\Ai
  3. Activate the virtual environment:
     .\.venv\Scripts\Activate.ps1
  4. Run the application:
     python -m uvicorn qa_agent:app --host 127.0.0.1 --port 8000


----------------------------------------------------------------------
STEP 2: OPEN THE WEB INTERFACE
----------------------------------------------------------------------
1. Open any web browser (Chrome, Edge, Firefox).
2. Go to this address: http://127.0.0.1:8000
3. A landing overlay will appear. Select your project (e.g. "ERP_Automation" or "kamyen") or type a name to create a new one, then click "Load Project Workspace".


----------------------------------------------------------------------
STEP 3: HOW TO RECORD A NEW WORKFLOW (MODULE 1)
----------------------------------------------------------------------
1. In the web interface, click on the tab: "📹 1. Flow Recorder"
2. Enter a unique "Flow Name" (e.g., "customer_add").
3. Enter the "Start URL" (e.g., OrangeHRM login page).
4. Click the green "Launch Browser" button. (This opens a chromium window).
5. In the web interface, click the red "Start Recording" button.
6. Now, go to the chromium window and click/type your actions manually.
7. Once finished, click "Stop Recording" in the web interface.
8. The recorded flow is saved under: D:\Ai\projects\<project_name>\flows\<flow_name>\


----------------------------------------------------------------------
STEP 4: HOW TO GENERATE AI TEST CASES & EXECUTE SUITE (MODULE 2)
----------------------------------------------------------------------
1. In the web interface, click on the tab: "⚙️ 2. AI Execution Platform"
2. Select your recorded flow from the "Active Business Flow" dropdown list.
3. Click "Run AI Post Analysis" to generate 10 unique positive, negative, and boundary test scenarios automatically.
4. Customize your Execution Profile:
   - Target URL
   - Authentication Required (Yes/No)
   - Chain Prerequisites (e.g. set it to "login" if you need to run login steps first)
5. Select the checkboxes of test cases you want to run.
6. Click "Start Execution". Playwright will execute the dependencies and target scenarios, generating a report with logs and screenshots!


----------------------------------------------------------------------
STEP 5: HOW TO VIEW STATS & ACTION CHECKLISTS (MODULE 3)
----------------------------------------------------------------------
1. Click on the tab: "📊 3. Project Console & Stats"
2. View the overall project scorecard (Total modules, Analyzed modules, Pending modules, and Total test cases).
3. The checklist table lists all your modules:
   - "🟢 Analyzed" modules are ready to execute.
   - "🟡 Unanalyzed" modules require AI analysis.
4. Click the blue "⚡ Run AI Analysis" action link directly inside the table row to run background analysis on any pending modules instantly!
