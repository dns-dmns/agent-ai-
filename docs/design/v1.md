## 2. System Setup & Launcher Scripts

### A. `run_server.bat`
```cmd
@echo off
echo ======================================================================
echo   Starting Enterprise AI QA Automation Platform Server...
echo ======================================================================

:: Kill existing process using port 8000
for /f "tokens=5" %%a in ('netstat -aon ^| findstr :8000') do (
    echo Stopping process PID %%a running on port 8000...
    taskkill /F /PID %%a >nul 2>&1
)

:: Activate virtual environment and start server
call .venv\Scripts\activate.bat
python -m uvicorn qa_agent:app --host 127.0.0.1 --port 8000 --reload
pause
```

### B. `STARTUP_GUIDE.txt`
```text
======================================================================
ENTERPRISE AI QA PLATFORM - STARTUP & TROUBLESHOOTING GUIDE
======================================================================

1. SETUP ENVIRONMENT:
   python -m venv .venv
   .venv\Scripts\activate
   pip install fastapi uvicorn playwright google-generativeai python-dotenv
   playwright install chromium

2. START SERVER:
   Option 1: Double-click "run_server.bat"
   Option 2: Run in terminal:
             python -m uvicorn qa_agent:app --host 127.0.0.1 --port 8000

3. TROUBLESHOOTING PORT 8000 CONFLICTS (ERRNO 10048):
   If port 8000 is blocked, run in CMD as Administrator:
     netstat -ano | findstr :8000
     taskkill /F /PID <PID_NUMBER>
```
